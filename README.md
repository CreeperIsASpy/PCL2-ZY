这是一个基于 PCL2 社区版的二次修改版本，添加自定义主题等增强功能，仅供 PCL2 赞助者提升体验使用。<br />
自定义主题功能违反官方开源协议，因此使用本项目源代码前请确保自己为赞助者，有权使用官方内部版本的隐藏主题功能，否则可能导致官方追责。<br />
本项目不提供任何二进制分发版本，可自行编译使用，对源代码的一切使用（包括对编译得到的二进制产物的使用）造成的一切法律责任由使用者本人承担。<br />
请勿在任何平台分发本项目的二进制版本，公开分发二进制产物属于违法行为。如有需求，本项目会积极配合官方追究分发者的法律责任。

本项目的修改尽可能确保不引发任何额外问题，若使用中遇到 Bug 或无法解决的问题请提交给上游，或加入上游的用户群询问。官方版本不存在的问题请勿反馈给官方。
